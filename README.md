# Breathe Studio

Site one-page en HTML / CSS / JS vanille.

## Lancer localement

Aucun build requis. Les modules ES nécessitent un serveur HTTP :

```bash
python -m http.server 8765
```

Puis ouvrir http://127.0.0.1:8765/

## Structure

```
index.html              Landing
style.css               Styles
script.js               Thème, curseur, magnetic, reveal, contact

mentions-legales.html
politique-de-confidentialite.html
politique-cookies.html
cgv.html

```
